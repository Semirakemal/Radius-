## Commands Practised

- pwd: Displayed the current working directory.
- whoami: Displayed the current username.
- hostname: Displayed the computer name.
- date: Displayed the current date and time.
- ls: Listed directory contents.
- ls -l: Displayed detailed file information.
- ls -la: Displayed all files, including hidden files.
- cd ..: Navigated to the parent directory.
- cd -: Returned to the previous directory.
- cd ~: Navigated to the home directory.
- mkdir -p: Created directories.
- touch: Created empty files.
- find: Located directories and README files.

## What I Learned

I learned how to navigate the filesystem using absolute and relative paths, inspect directory contents, identify my environment, and create an organized project structure.
