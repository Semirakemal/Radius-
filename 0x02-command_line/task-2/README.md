# Task 2

Practised creating, inspecting, copying, moving, renaming, and deleting files and directories.

## Commands Practised

"mkdir": Creates directories.
"touch": Creates files.
"echo": Writes text into files.
"cat": Displays file contents.
"head" and "tail": Display the beginning and end of files.
"wc -l": Counts lines.
"cp": Copies files.
"mv": Moves and renames files.
"rm": Removes files.
"ls -l": Displays file permissions.

Output Redirection

">" overwrites existing file content.
">>" appends content without deleting existing text.
