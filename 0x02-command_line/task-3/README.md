# Task 3

Practised locating files and searching for specific words using "find" and "grep".

## Commands Practised

- "find": Locates files and directories.
- "grep": Searches for specific words inside files.
- "grep -n": Displays matching line numbers.
- "grep -i": Ignores uppercase and lowercase differences.
- "grep -R": Searches recursively inside directories.
- "tee": Displays and saves command output.
- "cat": Displays saved search results.

## Difference Between find and grep

- "find" searches for files and directories by name or type.
- "grep" searches for specific text inside files.

## Combined Search

The "find" and "grep" commands can be combined to search for specific words only in selected files.
